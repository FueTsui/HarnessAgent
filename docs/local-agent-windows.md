# Harness Agent Windows 本地版

这是当前 Harness 智能体平台的 Windows x64 独立桌面应用，采用参考 Codex 的项目/任务侧栏、对话工作区、桌面标题栏和明暗主题。程序内置 Electron/Chromium、Python 运行时、锁定依赖和数据库迁移。无需安装 Python、Node.js 或使用系统浏览器打开界面。

## 使用

1. 将整个 ZIP 解压到普通目录；不要只取出 `HarnessAgent.exe`。
2. 双击 `HarnessAgent.exe`。应用自动启动本地服务，在同一个桌面窗口打开完整工作区。
3. 点击登录页“首次使用？查看本机登录信息”，使用生成的 `root` 账号和随机密码登录；也可从“应用”菜单查看。
4. 在后台配置模型提供商，并在智能体的模型设置中选择模型。全新数据目录带有“通用助手”，不包含模型权重或 API Key。
5. 关闭应用会先停止本次启动的任务服务。顶部“应用”菜单提供数据目录、日志及重启服务；后台设置直接在应用内打开。

默认只监听 `127.0.0.1`，从端口 `17650` 开始寻找可用端口；应用会自动连接。原有账户权限、工具审批、任务持久化与产物下载继续生效。

1.0.1 起不再预置知识库；首次升级会清理旧版两个已停用的平台知识库及其项目引用，保留用户自建知识库。应用 EXE、窗口和任务栏使用现有品牌 Logo，构建时生成并核验 16–256 像素的多尺寸图标。

快捷键：`Ctrl+N` 新建任务，`Ctrl+,` 设置；应用菜单中可查看其他键盘操作。桌面外框与已有主题设置同步。

## 数据与升级

默认用户目录为 `%LOCALAPPDATA%\HarnessAgent`：

| 路径 | 用途 |
| --- | --- |
| `.env` | 模型等可选环境配置、登录初始化配置、加密密钥 |
| `first-run.txt` | 初次登录信息；改密后该初始密码失效 |
| `data/app.db` | 用户、智能体、模型配置、任务、对话及运行记录 |
| `data/` 其他子目录 | 附件、知识库、技能资源、工作区及导出文件 |
| `logs/` | 本地运行日志 |
| `runtime.json` | 当前启动状态及地址，不含密钥 |
| `desktop/` | 桌面窗口的浏览器配置与本地界面缓存（具体名称以应用生成目录为准） |

每个数据目录只允许一个实例。第二次启动会保留原密码、密钥和数据。
升级时先关闭应用，备份整个用户目录，再解压新程序到新目录启动。数据库自动迁移；不要用旧版本直接打开已经升级的数据目录。
备份必须包含 `.env`，丢失加密密钥会导致已保存的模型、MCP 等凭据无法解密。分享程序只分享干净发布 ZIP，不要分享用户目录。

本地版默认建立独立数据，不会读取原项目 `.env` 或复制原来的账户、模型 Key 和聊天记录。

## 自定义运行

指定用户目录：

```powershell
.\HarnessAgent.exe --home "D:\AgentData"
```

仅运行后台服务（高级用法）：

```powershell
.\runtime\python.exe -X utf8 .\app\local_agent.py serve --home "D:\AgentData" --port 17650
```

前台可用 `Ctrl+C` 停止；托管程序可通过 stdin 写入 `stop` 加换行并等待优雅退出。
`--port 0` 会选择系统分配端口。`--managed` 表示 stdin 关闭时自动停止，供桌面应用使用。
本地版固定使用用户目录中的 SQLite、工作区和回环监听，忽略外部同名数据库/目录环境变量；其他配置从用户目录 `.env` 读取。

## 能力边界

- Agent 编排、对话、数据库和调度在本机运行。模型推理依赖你配置的服务；使用云模型需要网络和相应 API 凭据。
- 可在后台配置已运行的 Ollama、LM Studio 等 OpenAI 兼容本地模型接口。程序不附带模型权重或推理引擎。
- 应用窗口的 Chromium 已内置；Agent 的浏览器工具仍使用系统 Chrome/Edge。Git、TypeScript 和用户注册的 MCP/编程服务需要其对应程序。
- Python 代码诊断、PDF/DOCX/PPTX/XLSX 处理依赖已打包。受限 Shell 保持原项目默认关闭状态。
- 保留原平台登录、权限、审批和工具分配规则。
- 适用于 Windows 10/11 x64。发布 EXE 未进行代码签名。

## 从源码构建

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build_desktop.ps1
```

构建使用官方 Electron、CPython 嵌入式运行时、SHA-256 校验和 `requirements.lock` 的哈希锁定依赖。
只复制明确列出的应用文件，不打包开发环境、原数据库、`.env`、测试记录或参考仓库。
桌面发布目录为 `dist/HarnessAgent-Desktop`，ZIP 与校验信息见构建命令输出。`tools/build_windows.ps1` 的旧控制台版本仅用于内部运行时封装，不是桌面版的交付入口。现有 `RELEASE.md` 的公网生产部署流程与此回环本地分发包是不同的部署目标。
